# 盒隙 BLINDGAP — 官网 + 桌宠（monorepo）

本仓库包含三部分：

| 目录 | 内容 | 说明 |
| --- | --- | --- |
| 根目录 | 盲盒平台 Web（官网首页，兼容移动端） | 部署在云服务器 8080 |
| `pet/` | 盲盒平台 Web 版桌宠（PWA） | 部署在云服务器 8081，手机可「添加到主屏幕」 |
| `pet-desktop/` | **桌面版桌宠（Electron 悬浮球）** | 系统级透明置顶浮窗，可拖到屏幕任意位置 |

---

## 一、盲盒平台 Web（根目录）

依据《IP盲盒平台 PRD V1.1》实现首页核心闭环：
**氛围页 → 21s 无缝视频《暗潮》（无播放器痕迹）→ 末帧开盒台（8 个封着的盒子，4×2）→ IP 揭示卡 → 图鉴墙（第六大道花名册）**

### 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
npm run test     # 逻辑层单测（14 个：概率/保底/图鉴）
npm run build    # 产物在 dist/
```

### 资产契约（放图即生效，零代码改动）

| 路径 | 用途 | 缺失时表现 |
| --- | --- | --- |
| `public/assets/anchao.mp4` | 首页 21s 故事视频 | 静态封面 + 直出开盒按钮（流程不中断） |

当前可用编号：000/001/002/005/006/007/009–020（已有立绘）；003/004/008 素材待补充（图中为暗格"入住筹备中"）。

### 赌盒六选一（互动抽盒）

故事末帧那一屏就是开盒台：直接摊出 **8 个封着、看不见内容的盒子（4×2 排布）**，盒子上**不贴任何系列标签、不显示档位、悬停也不预览**——

- **真·盲盒**：服务端对未拆的盒子连 `rarity` 都不下发（只回 `{ opened: false }`），前端拿不到任何线索，纯凭手气赌一只
- **首抽不再强制老皮**：老皮（№000）改为约 1% 概率的「偶发彩蛋」随机掉落，既不强制首抽，也保证图鉴里的 000 仍可集齐
- 档位走公示掉率（路面 55% / 限定 33% / 狠货 10% / 幽灵 2%）；**保底到期时整批都是该档位**（内容不可见，只有整批同档才能保证「赌哪只都兑现」）
- 整批同档的批（保底批）拆掉一个后，剩下的自动换回常规档位，避免被连拆 8 张
- 不满意可「换一批」，每天 2 次；**一旦拆过，这一批就锁死**，不能整批换掉
- 拆开的盒子留在原位：显示「打开的样子」——盒盖斜倚在一角 + 露出真身立绘 + 名字编号，一眼看出「这个被拆开了」，不可再点
- 服务端用 `offers` 表校验「只能从这一批里挑、每个盒子只能拆一次」，前端改不了结果

### 结构

- `src/data/ips.ts` — IP 数据源（PRD 8.1/8.3 文案已录入）
- `src/data/subtitles.ts` — 21s 字幕时间轴（视频优化版交付后只需改秒数）
- `src/logic/offer.ts` — 一批 8 个盒子的生成规则（纯函数，前后端共用同一语义）
- `src/logic/boxReducer.ts` — 抽盒概率 + 保底（小10/大40/幽灵硬90，与服务端同语义）
- `src/logic/collection.ts` — 图鉴收录/端盒判定
- `src/screens/` — Landing / Story / EndCard（开盒台）/ Opening / Reveal / Wall / Auth
- `src/logic/track.ts` — 埋点 stub（事件名按 PRD 第十章）

### 待接后端

抽数/保底计数目前 localStorage 模拟（`src/logic/storage.ts`）；接服务端时替换该适配层即可，`boxReducer` 语义可直接复用为服务端实现参考。
